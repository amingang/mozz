راهنمای اجرای نسخه مرتب‌شده سایت مدیریت سفر

۱) تمام فایل‌های این پوشه را کنار هم نگه دار.
۲) فایل «عکس پس زمنیه.jpg» برای پس‌زمینه استفاده می‌شود؛ نام آن را تغییر نده.
۳) برای شروع، فایل index.html را باز کن.
۴) فایل‌های JavaScript، CSS و HTML از هم جدا شده‌اند. دکمه‌ها در JavaScript مدیریت می‌شوند و استایل‌ها در style.css قرار دارند.

نکته: اطلاعات اعضا، وسایل و هزینه‌ها در localStorage مرورگر ذخیره می‌شوند. اگر می‌خواهی اطلاعات آزمایشی قبلی حذف شوند، می‌توانی از تنظیمات ذخیره‌سازی همان سایت در مرورگر پاکشان کنی؛ این کار اطلاعات ذخیره‌شده را حذف می‌کند.
